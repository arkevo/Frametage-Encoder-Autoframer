# Reframe stage, install step 2 of 2: everything that is not torch.
# install.sh installs this file into .venv-reframe/ only AFTER
# requirements-torch.txt, then checks that torch is still the CUDA
# build: a package installed later can silently replace it with a build
# from PyPI. Never install either file into the encoder's .venv: the
# encoder is standard-library only and must not inherit a
# multi-gigabyte CUDA stack.
#
# To install by hand, use the reframe environment's interpreter
# (.venv-reframe/Scripts/python.exe on Windows, .venv-reframe/bin/python
# on Linux) and keep this order:
#   <python> -m pip install -r ftea/reframe/requirements-torch.txt
#   <python> -m pip install -r ftea/reframe/requirements.txt

#
